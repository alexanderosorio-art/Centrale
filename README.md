# Price List Normalizer

Aplicación Streamlit para convertir listas de precios de proveedores en un
archivo Excel compatible con el CRM.

## Ejecutar localmente

```powershell
pip install -r PriceListNormalizer/requirements.txt
streamlit run PriceListNormalizer/app.py
```

## Despliegue en Streamlit Community Cloud

- Repositorio: este repositorio de GitHub.
- Rama: `main`.
- Archivo principal: `PriceListNormalizer/app.py`.
